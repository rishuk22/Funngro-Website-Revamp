# Funngro Website Revamp — Project Submission

A responsive front-end concept with a home page plus the two requested pages:
- `company.html` — For Companies
- `teen.html` — For Teens

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser. No build step or package installation is required.

## Files
- `index.html`: landing page and navigation
- `company.html`: company-focused page
- `teen.html`: teen-focused page
- `styles.css`: responsive layout and visual design
- `script.js`: mobile navigation and smooth anchor scrolling

## SEO included
- Unique page titles and meta descriptions
- Semantic HTML landmarks and heading hierarchy
- Mobile viewport metadata
- Open Graph metadata
- Canonical URL placeholders (update these if publishing to a different domain)
